# Питомец Финни — ЛЦТ 2026

Детское Android-приложение, которое помогает осваивать планирование карманных денег через заботу о виртуальном питомце.

## Материалы

- `PetFinny-LCT2026.pptx` — презентация команды.
- `Техническое-описание.pdf` и `.docx` — описание реализации и требований ТЗ.
- Исходный код и APK — в разделе [Releases](https://github.com/puPAKA/pet-finny-lct2026/releases).

## Сборка

Распакуйте исходный архив и откройте проект в Android Studio. После синхронизации Gradle выберите конфигурацию `app` и запустите приложение на эмуляторе или подключённом Android-устройстве.
